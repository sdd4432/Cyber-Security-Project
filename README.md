# 🛡️ CyberGuard

## Cyber Security Awareness & Threat Detection System

CyberGuard is a web-based cybersecurity awareness and threat detection system designed to help users understand basic security risks and check the security status of an application.

### 🚀 Features

- 🔐 Password Security Checker
- 🚨 Threat Detection
- 🎣 Phishing Awareness
- 🔍 Security Scanning
- 📊 Security Score
- 🕒 Scan History
- 🌐 URL Security Checking
- 💾 MongoDB database integration

### 🛠️ Technologies Used

- React.js
- Vite
- Python
- Flask
- MongoDB
- HTML
- CSS
- JavaScript
